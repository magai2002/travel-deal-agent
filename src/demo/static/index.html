Travel Deal Agent

Ask about a trip and this triggers the real pipeline: a Claude call reads your request, then a live Flixbus price check runs and gets scored against the same deal logic the production agent uses. Only Brussels ↔ Paris has real data behind it — everything else gets a friendly explanation of why.

One request per visitor per day, plus a small daily cap overall — this is a portfolio demo, not a hosted service. Full source (the daily batch agent, the config/price assistant, and this demo) is linked from the project README.
